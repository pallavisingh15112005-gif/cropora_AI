College mini project · CSE (AI & ML)

Cropora AI

Status: Prototype · Demo data

Ek chat-based bot jo kisan ko fasal ka aaj ka mandi bhav, kal se badlaav, aur ek chhoti salah deta hai. Kisan ko bas fasal ka naam likhna hai.

Demo dekhein Kaise kaam karta hai

Problem kya hai?

Kisan ke saamne

  • Mandi ke bhav ki jaankari sirf mandi jaakar ya agent se milti hai.
  • Sarkari portal par data hai, par English aur tables mein, jo har kisan ke liye aasan nahi.
  • Ek hi fasal ka bhav do mandiyon mein alag hota hai, aur faisla karna mushkil hota hai.

Hamara hal

  • Seedha sawaal: "aloo ka bhav kya hai?" likhne par jawab.
  • Hindi mein, saaf numbers aur ek seedhi salah ke saath.
  • Mobile par chalta hai, bina app install kiye.

Kaise kaam karta hai

Data pipeline se leke jawab tak, ek seedha raasta.

Step 1Data lenaAgmarknet se roz ke mandi bhav fetch karna.
→
Step 2Saaf karnaFasal ke naam, mandi aur tareekh ko ek format mein laana.
→
Step 3Sawaal samajhnaKisan ke likhe Hindi ya English text se fasal aur mandi pehchanna.
→
Step 4Jawab bananaBhav, kal se badlaav, aur salah ek chhote card mein.
→
Step 5Chat mein dikhanaMobile-friendly chat screen par jawab dikhna.

Features

Ek sawaal, ek jawab

Fasal ka naam likhna kaafi hai. Lambi form ya menu nahi.

Sabhi bhav ek jagah

"Sabhi bhav" likhne par saari fasalon ka grid dikhta hai.

Salah ke saath bhav

Bhav 5% se zyada badle to bot seedhi salah deta hai: bechna hai ya ruknaa hai.

Login aur demo

Login page se account ka dikhawa, aur "yaad rakho" option.

Dark mode aur mobile

Phone ki theme ke hisaab se badalta hai. Chhoti screen par poori jagah leta hai.

Hindi-first

Devanagari font aur Hinglish sawaal dono samajhta hai.

Tech stack

FrontendHTML, CSS, vanilla JavaScript. Ek hi file, koi build step nahi.
DataAgmarknet (data.gov.in) ka daily mandi bhav, CSV ya API se.
Bot logicKeyword se fasal aur mandi pehchan, phir template se jawab.
Next (planned)Chhota backend, asli login, aur daily data refresh.
